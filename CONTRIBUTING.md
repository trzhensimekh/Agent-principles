# Contributing

AGENT is an experimental architecture proposal. Contributions should make it easier to falsify, reproduce, or apply.

High-value contributions:

- a realistic maintenance task where a principle helps or fails;
- a controlled comparison with pinned models, harnesses, budgets, and environments;
- a bypass or false positive in a reference check;
- a missing effect, configuration, schema, or runtime dependency;
- a correction to evidence or prior-art attribution;
- a smaller mechanism that achieves the same verified outcome.

For empirical claims, include task and repository revisions, raw run records, acceptance checks, failed runs, full cost accounting, and limitations. Follow [the protocol](benchmarks/PROTOCOL.md). Negative results are welcome. Never substitute synthetic fixtures for actual agent measurements.

For code changes, provide a reproducible case and run affected checks. For source corrections, link to the primary paper, official documentation, or original implementation and state the relevant version/date. Do not paste proprietary source dumps or unattributed text into this repository.

Keep repository content in English. By submitting a contribution, you agree to license your original prose under CC BY 4.0 and your original code under MIT, consistent with [LICENSE](LICENSE) and [LICENSE-CODE](LICENSE-CODE).
